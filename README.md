# 📱 My Projects Overview

У цьому репозиторії міститься три окремі проєкти:

---

## 📁 MyApplication

### 📌 Опис
Це навчальний мобільний застосунок, який реалізує один інтерактивний екран задачі.

---

### 🧩 Основний функціонал

Екран містить **картку задачі**, яка включає:

- Назву задачі (наприклад: *"Вивчити мобільну розробку"*)
- Пріоритет задачі:
  - Низький
  - Середній
  - Високий
- Кольоровий індикатор пріоритету (візуальний маркер)

---

### 🔘 Інтерактивність

- Кнопка **"Позначити виконаною"**
  - перемикає статус задачі
  - змінюється на **"Відмінити"** при виконанні

- Стани задачі:
  - Не виконана → 🔴
  - Виконана → ✅

---

### ✍️ Додаткові UI ефекти

- Назва задачі перекреслюється після виконання
- Колір тексту змінюється на сірий
- Лічильник натискань:
збільшується при кожному кліку

---

## 📁 MyApplication2

### 📌 Опис
Це повноцінний навчальний мобільний застосунок — **Трекер боргів**, **тема 16**.

Проєкт реалізує багатосторінкову архітектуру, локальну базу даних, API взаємодію та біометричну автентифікацію.

---

### ⚙️ Основні можливості

- 📋 Список боргів (LazyColumn)
- 📄 Деталі боргу
- ➕ Додавання людини та боргу
- 💰 Погашення боргу (часткове / повне)
- 🔄 Синхронізація через Fake API + WebSocket
- 🔐 Біометрична автентифікація (Fingerprint / Face ID)
- 🔒 Екран блокування застосунку
- ⚙️ Екран налаштувань безпеки
- 👤 Профіль користувача

---

### 🧱 Архітектура

- MVVM (ViewModel + Repository)
- Room (локальна база даних)
- StateFlow для станів UI
- Jetpack Navigation Compose
- Biometric API
- Fake WebSocket сервер (імітація реального часу)

---

### 🔐 Безпека

- Біометрія як додатковий рівень захисту
- Налаштування увімкнення/вимкнення біометрії
- Збереження налаштувань через SharedPreferences
- Автоматичний lock-екран при старті (за умовою)
