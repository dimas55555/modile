# 📱 My Modile Overview

У цьому репозиторії міститься три окремі проєкти:

---

## 📁 MyApplication

### 📌 Опис
Це навчальний мобільний застосунок, який реалізує один інтерактивний екран задачі.

---

### 🧩 Основний функціонал

Екран містить **картку задачі**, яка включає:

- Назву задачі (наприклад: *"Вивчити мобільну розробку"*)
- Пріоритет задачі:
  - Низький
  - Середній
  - Високий
- Кольоровий індикатор пріоритету (візуальний маркер)

---

### 🔘 Інтерактивність

- Кнопка **"Позначити виконаною"**
  - перемикає статус задачі
  - змінюється на **"Відмінити"** при виконанні

- Стани задачі:
  - Не виконана → 🔴
  - Виконана → ✅

---

### ✍️ Додаткові UI ефекти

- Назва задачі перекреслюється після виконання
- Колір тексту змінюється на сірий
- Лічильник натискань:
збільшується при кожному кліку

# 📁 MyApplication2

## 📌 Опис
DebtTracker — мобільний Android-застосунок для обліку боргів та контролю повернення коштів.  
Додаток реалізує багатосторінкову архітектуру, локальне збереження даних, емуляцію мережевої синхронізації через WebSocket та підтримку біометричної автентифікації.

---

# 🚀 Технологічний стек

Проєкт реалізовано з використанням Android-native стеку:

- Kotlin — основна мова програмування
- Jetpack Compose — декларативний UI toolkit
- Material Design 3 — сучасні UI-компоненти та стилізація
- Navigation Compose — навігація між екранами
- Room Database — локальна SQLite база даних
- StateFlow — реактивне оновлення UI
- ViewModel — управління станом екранів
- SharedPreferences — локальне збереження налаштувань
- Android Biometric API — підтримка Face ID / Fingerprint
- Mock WebSocket / Fake API — емуляція серверної синхронізації
- JUnit + MockK — тестування логіки застосунку

---

# 🗂️ Основні моделі даних

## 👤 PersonEntity
Модель людини, якій належить борг.

### Поля:
- `id: Int` — унікальний ідентифікатор
- `name: String` — ім’я людини
- `phone: String` — номер телефону
- `email: String` — email користувача
- `isTrusted: Boolean` — статус довіри
- `createdAt: Long` — дата створення запису

---

## 💰 DebtEntity
Основна модель боргу.

### Поля:
- `id: Int` — ідентифікатор боргу
- `personId: Int` — власник боргу
- `title: String` — назва боргу
- `initialAmount: Double` — початкова сума
- `currentAmount: Double` — поточний залишок
- `isReturned: Boolean` — чи погашено борг
- `dueDate: Long` — дата повернення
- `syncStatus: String` — стан синхронізації

---

## 💳 PaymentEntity
Модель погашення боргу.

### Поля:
- `id: Int` — ідентифікатор платежу
- `debtId: Int` — ID боргу
- `amount: Double` — сума платежу
- `createdAt: Long` — дата оплати
- `comment: String` — коментар до платежу

---

# 🗂️ Архітектура застосунку

- `ui/` — Compose екрани

---

# 🌐 Робота з даними та синхронізація

Додаток працює за принципом Offline-first.

Всі дані:
1. Спочатку записуються в локальну Room БД
2. Потім можуть синхронізуватись із сервером

Для демонстрації реалізовано:
- FakeApiService
- Mock WebSocket connection
- Sync status для кожного боргу

### Стани синхронізації:
- `pending`
- `synced`
- `error`

---

# 🔐 Біометрична автентифікація
